# Curation rules

1. One authoritative home per procedure. If a skill supersedes text elsewhere, the
   other text links here and does not repeat the procedure.
2. Every skill names its sources in a `Sources` section and its checks in a `Verified`
   section. A claim that is neither checked nor recorded does not belong in a skill.
3. Stale guidance from historical sources is fixed during migration, and the fix is
   recorded in `HISTORY.md`.
4. Relative references must resolve. The batch check is a link walk over `skills/**`.
